# Кинодневник — заметки для работы над кодом

Личный дневник фильмов, сериалов, мультфильмов и аниме. Сайт: https://mykyta20.github.io/kinodnevnik/ (GitHub Pages из ветки `main`, обновляется примерно за минуту после пуша). Владелец пишет по-русски и не программист: объяснять просто, по шагам, без жаргона; в итоге — что изменилось на сайте и что ему нужно сделать (обычно ничего).

## Главные правила
- **Записей в репозитории нет и не должно быть.** Они лежат в личной Google-таблице владельца.
- **Код Apps Script (`Code.gs`) не менять.** Он вшит в `index.html` как `<script id="code-gs">` только для инструкции по установке; настоящая копия развёрнута у владельца, и переразвёртывать её он не хочет. Всё новое делается на стороне сайта через существующие действия `getAll`, `saveItems`, `deleteItems`, `replaceAll`.
- **Владелец не работает с таблицей и Apps Script напрямую.** Всё, что нужно ввести (ключи, настройки), вводится на сайте.
- Дневник работает онлайн, в основном на Mac. Мобильная версия — низкий приоритет.
- Перед пушем в `main` — тесты (см. ниже). Настоящую таблицу владельца в тестах не трогать.

## Устройство
- Весь сайт — один файл `index.html`: шрифты (строка с `@font-face` в base64, ~200 КБ, не трогать), CSS (`#app-css`), Code.gs (`#code-gs`), приложение (`#app-js`, одна IIFE без сборки). Плюс `manifest.webmanifest` и иконки.
- **Хранилище** (`Store`): в режиме Google сайт шлёт `POST` с `{key, action, arg}` на адрес веб-приложения Apps Script. Адрес и ключ хранятся в `localStorage` (`kinodnevnik:remote`), на новое устройство переносятся «ссылкой подключения» из раздела «Данные». Сохранение пакетное с задержкой ~1 с; при ошибке — повтор каждые 6 с. `Store.touch(it, true)` — «тихая» правка (постер): не меняет `updated`, по которому сортируется «Хочу посмотреть». Ответ без поля `data` считается ошибкой (Google иногда отвечает «пустышкой» как на GET).
- **Служебная запись** `id: "__settings"` (`cat: "settings"`, поле `cfg`) лежит в той же таблице; сайт вынимает её при загрузке (`takeCfg`) и прячет из списков, сохраняет через `saveItems`, переносит при `replaceAll`. Там лежат: `cfg.tmdb` и `cfg.omdb` — ключи TMDB и OMDb, `cfg.goals` — цели на год (`{'2026': {n: 80, de: 10}}`, `de` — «на немецком»), `cfg.goalHide` — год, в который владелец сказал «Не сейчас», `cfg.recNo` — TMDB-ссылки, которые не советовать (до 300).
- **Тайтл** (основные поля): `id`, `cat` (`film`, `series`, `cartoon`, `toon` мультсериал, `anime`, `animefilm`), `title`, `orig`, `year` (у сериалов «2011–…» или «2003–2019»), `status` (`done`, `watching`, `paused`, `dropped`, `planned`), `rating` 1–10, `verdict`, `pros`, `cons`, `notes`, `dates` (ISO), `dub` (озвучка), `progress`, `fav`, `rewatch`, `rec`, `tags`, `img` (постер), `noimg` (владелец пропустил или убрал постер — подбор этот тайтл не трогает), `ext` (`imdb`, `kp` — вписываются вручную; `tmdb`, `shiki` — оценки баз при добавлении; `omdb` — `{imdb, votes, rt, mc, d}` из OMDb, обновляется раз в 30 дней), `info` — коротко из TMDB/Shikimori для афиши: `bg` (кадр: путь TMDB или полный адрес Shikimori), `g` (до 3 жанров), `rt` (минуты; у сериалов — серия), `ns` (сезонов), `ne` (эпизодов аниме), `dir` (режиссёр / создатели / студия), `at` (дата). Описание, слоган и актёры в таблицу не пишутся — они в `localStorage` (`kinodnevnik:plot`, до 400 тайтлов), чтобы таблица оставалась лёгкой. У аниме: `mal` (номер MyAnimeList = Shikimori), `aod` (средняя оценка аниме-баз, июль 2026), `slabel`, `franchise`, `parts` — сезоны/фильмы (`label`, `title`, `kind` tv/film/ova, `year`, `status`, `rating`, `dates`, `mal`, `img`, `orig`, `dub`, `progress`). Статус и даты аниме с частями считаются из частей (`syncParts`). У фильмов из TMDB: `tmdb` («movie/123» или «tv/456»), `imdb` («tt…»).
- **Поверх дневника** открываются полноэкранные режимы со своим адресом: `#rate` — «Быстро оценить» (`QR`), `#credits/2025` — «Итоги года» (`CR`). «Назад» в браузере и Esc их закрывают.
- Кэши в браузере: `kinodnevnik:tints` (цвета постеров), `kinodnevnik:plot` (описания), `kinodnevnik:recs` (советы на сутки).
- Около 500 тайтлов из истории HDrezka (2020–2026). У всех 118 аниме есть `mal` и постер с cdn.myanimelist.net; фильмам, сериалам и мультфильмам постеры подбираются кнопкой в «Данных» (см. «Сделано»).

## Внешние базы (из браузера, без своего сервера)
- **TMDB** `https://api.themoviedb.org/3`, `language=ru-RU`, ключ из `S.cfg.tmdb` (32 символа идут параметром `api_key`, длинный токен — заголовком `Bearer`). Постеры `https://image.tmdb.org/t/p/w342…` (в превью `w185`/`w92`). CORS открыт. Для подбора постеров — `/search/movie` (`year`) и `/search/tv` (`first_air_date_year`), подробности с `append_to_response=external_ids` (IMDb), для афиши — `credits,external_ids` (кадр `backdrop_path` в `w1280`, жанры, длительность, режиссёр, 4 актёра; нет русского описания — берётся `en-US`); советы — `/{movie|tv}/{id}/recommendations`. На 429 и обрыв связи — повтор с паузой (`retry`). Обязательная пометка про TMDB есть в «Данные» → «Откуда данные».
- **Shikimori** GraphQL `https://shikimori.io/api/graphql` (POST, CORS открыт, без ключа, лимит ~5 запросов/с). Старый домен shikimori.one из браузера не отвечает. Поля: `animes(search:, ids:, limit:)` → `id malId name russian english kind score status airedOn{year} releasedOn{year} franchise poster{main2xUrl mainUrl previewUrl} related{relationKind anime{…}}`.
  Для афиши аниме: `animes(ids:)` → `description genres{russian} studios{name} duration episodes screenshots{originalUrl}`; если Shikimori не знает поле, запрос повторяется проще (`description genres{russian}`). Разметку `[character=…]…[/character]` и `[[…]]` из описания убирает `shikiText`. Не чаще раза в 220 мс (`shikiSlot`).
- **OMDb** `https://www.omdbapi.com/?i=tt…&apikey=…` — оценки IMDb (с числом голосов), Rotten Tomatoes, Metacritic. Бесплатный ключ (1000 запросов в день) владелец получает сам по шагам в «Данные» → «Описания и оценки»; ключ можно вставить и целой ссылкой из письма. На неверный ключ и на кончившийся лимит OMDb отвечает 401 — различаются по тексту (`getJSON`). Пометка про OMDb — в «Откуда данные».
- Jikan (api.jikan.moe) из браузера недоступен.

## Дизайн «Кинозал»
Тёплая тёмная тема по умолчанию (фон `#0F0D0C`, янтарный акцент `#F0A640`), светлая «Дневной сеанс». Цвета задаются переменными в `:root` (и для светлой темы в двух местах: `prefers-color-scheme` и `[data-theme="light"]`). Шрифты: заголовки Literata, текст Golos Text. Цвета разделов: фильмы `--c-film` (красный), сериалы `--c-series` (бирюзовый), мультфильмы `--c-cartoon` (салатовый), аниме `--c-anime` (фиолетовый). Оценки — «лампочки» `.badge.rvN`. В строках всех списков — обложка `.cover`: корешок цвета раздела `.spine` + постер `.pic` 40×60 (на телефоне 36; постеры TMDB в размере `w92`; без постера видна первая буква названия). Карточка тайтла подсвечивается цветом постера: `--tint` (зарегистрирован через `@property`, плавно перетекает), цвет считается на canvas (`dominant`) и кэшируется в `localStorage` (`kinodnevnik:tints`: `c` адрес→цвет, `bad` сайты без CORS). Для MyAnimeList, если он не даёт читать картинку, — одна попытка на браузер, дальше цвет раздела.
Карточка-афиша: вверху «экран» `.screen` (кадр 2.39:1 с подсветкой цветом постера), постер заходит на него (`.d-head.lifted`), ниже длительность и жанры, режиссёр, слоган, описание с «Читать полностью», актёры и плитки оценок мира `.wt` (IMDb, Rotten Tomatoes с помидором, Metacritic в цвете оценки, TMDB, Кинопоиск, аниме-базы). Верх карточки — блок `#d-hero`, перерисовывается отдельно (`repaintHero`), когда приходят данные. «Быстро оценить» — тёмный зал с размытым кадром, крупный постер, ряд лампочек (на телефоне 5×2), финал «Конец». «Итоги года» — всегда тёмный зал с плёночным зерном, титры плывут вверх (`transform`, своя скорость под длину года). Цель — кольцо `ringSVG`. Загрузка — плёночный отсчёт `.leader`; отметка просмотра — билетик `#ticket`.

## Тесты
`tests/` — Playwright-стенд: сайт открывается по адресу GitHub Pages, а Google-таблица (поведение как у Code.gs), TMDB, Shikimori и картинки подменены (`tests/harness.js`). Запуск из папки `tests`: `node t1.js && node t2.js && node t3.js && node t4.js && node t5.js && node t6.js` (нужен Playwright с Chromium; Playwright сам CORS не проверяет, поэтому запрет картинок MyAnimeList/Shikimori стенд изображает явно; OMDb тоже подменён, ключ стенда — `H.OMDB_KEY`; опция `now` «замораживает» дату). Скриншоты складываются в `tests/shots/` (в git не идут). Сейчас 245 проверок: умное добавление, сезоны аниме, ключ TMDB, сбои баз, телефон, светлая тема, «пустые» ответы Google; `t4.js` — подбор постеров (уверенные и спорные совпадения, пауза, 429, отзыв ключа, сохранение пачками), подсветка карточки и постеры в строках списков; `t5.js` — афиша (TMDB, Shikimori, английское описание, упрощённый запрос), OMDb (ключ, плитки, лимит, неверный ключ), «Обновить всё сразу», сортировка по IMDb, «Быстро оценить»; `t6.js` — цель на год, «Что посмотреть дальше», мелкие штрихи, «Итоги года».

- Постеры для записанных тайтлов (17.10.2026): «Данные» → «Постеры для записанных тайтлов». Фильмы, сериалы, мультфильмы без `img` ищутся в TMDB по `orig`, `title` и году (3 запроса параллельно). Уверенно (`surePick`): то же название, год ±1, тот же тип; из одинаковых — только если один в 10 раз известнее. Уверенные сохраняются сами (`img`, `tmdb`, `imdb`, `ext.tmdb`) пачками по ~20 через `saveItems`; спорные и ненайденные — карточки с вариантами, поиском по другому названию и «Пропустить» (`noimg`). Пауза/продолжение; после перезагрузки подбор начинается с оставшихся. В карточке тайтла: «Найти постер», «Сменить постер» (в «Название, год, раздел»), «Убрать постер» (убирает и ссылки TMDB/IMDb, ставит `noimg`). Подсветка карточки цветом постера.
- Постеры в строках всех списков (17.10.2026): «Обзор», разделы, «Хочу посмотреть», поиск, статистика.
- Карточка-афиша и оценки мира (17.10.2026): кадр, описание, жанры, длительность, режиссёр, актёры; IMDb / Rotten Tomatoes / Metacritic через OMDb (ключ в «Данные» → «Описания и оценки», там же «Обновить всё сразу» с прогрессом); сортировка «По оценке IMDb».
- «Быстро оценить» (17.10.2026): пункт меню с числом тайтлов без оценки и кнопка на «Обзоре». Очередь — просмотренное без оценки, кроме брошенного, свежее первым; цифры 1–9 и 0 (=10), → пропустить, ← назад с отменой, «Не досмотрел», «Открыть карточку», вердикт по желанию.
